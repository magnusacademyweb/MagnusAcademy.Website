Staff Upload

Upload a CSV/Excel file with one row per student per exam, and columns: roll_number, full_name, class, exam_name, exam_date, Physics, Physics Max, Chemistry, Chemistry Max, Maths, Maths Max, Biology, Biology Max. exam_date is required for every row. Leave a subject blank if the student didn't take it. Each subject has its own max — e.g. NEET's Biology is usually worth more than Physics/Chemistry. If a roll number isn't already registered, it will be auto-created using the full_name and class columns — full_name is required for any new roll number. If an entry for the same student/subject/exam/date already exists, you'll be asked to confirm before it's overwritten.
